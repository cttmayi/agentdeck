# 示例工具（example-note）

这是一个**照着抄就能上手**的工具包：一个目录、两个文件、两个动作。

```
example-note/
  tool.json              ← 机器读的清单（平台按它判断"这是不是一个工具"）
  TOOL.md                ← 你正在读的这份说明（人读，可选）
  scripts/note.mjs       ← 包级入口（清单里的 entry）
  scripts/clean.mjs      ← 第二个动作自己的入口
```

- **一个包 = 一个组**：装一次，里面的动作一起进来；授权也是按组给。
- 动作在判决里的名字带组命名空间：`example-note.append-note`。
- `dir` 是**绑定参数**（平台按事实填工作目录），模型看不见也填不了；
  `text` 是**开放参数**（模型填，上限 2000 字）。
- 两个动作都声明了 `dryRun: supported`，所以它们有资格被自动执行；
  写 `unsupported` 的动作只能产出"建议"，必须有人显式开启才会真的跑。

写自己的工具时：复制这个目录，改 `tool.json`，把脚本换成你要做的事。

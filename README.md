# alpha-helper

一个**跑在自己机器上**的 AI 工作台。它做三件事：

1. 把外部的报告 / 事件收进来；
2. 让本机的 agent 按你写的标准去**审核**，产出**结构化的判决**；
3. 由判决触发**有界的动作**（评论、改状态、打标签、指派 agent）。

判决是闭合的（结论 / 理由码 / 严重度 / 证据 / 动作），只有一处开放字段留给模型自由发挥。
这是刻意的——**能被程序可靠处置的判断，和一个需要人读的段落，是两种东西。**

> 📌 **这份文件是给使用者的**：怎么跑起来、怎么用、你必须知道的风险。
> 给开发者看的（代码结构、开发命令、技术选型、不变量）在 [`docs/README.md`](./docs/README.md)。

## ⚠️ 先读这一段：安全边界

> 这一节对应 `requirements.md` 的 `NFR-SEC-01` / `NG7` / `A11`。**它是必读的，不是免责声明。**

| 项 | 事实 |
|---|---|
| **不做沙箱隔离** | 默认情况下，run **以你启动 daemon 的那个 OS 用户的完整权限执行**，可以读写你账户能碰到的任何文件 |
| CLI 权限模式 | 无人值守所必需，因此不弹任何确认 |
| 没有做的事 | 不做文件系统沙箱、不做容器 / microVM、不做凭据代理 |
| "代码不出本机"的真实含义 | **工作目录不出本机**；但 agent 读写并写进报告 / 判决的内容**会回到远端** |
| 远端存有什么 | 账号与设定、记录副本。远端**不存**任何第三方 payload |

**把 daemon 当作"你自己"来运行。** 它不是一个受限的执行环境。

### 可选沙箱（`--sandbox workdir-write`）

```bash
pnpm run daemon --sandbox workdir-write
```

注意这里**没有** `-- --sandbox`：那个写法会让 `--sandbox` 被当成位置参数而**静默失效**
——沙箱根本没开，而你以为开了。所以遇到 `--` 会直接报错（见下面的说明）。

它**只允许写工作目录**，读不受限（agent 本来就要读 CLI 安装位置、`node_modules`、语言工具链）。

**它仍然不是安全边界。** 请把这句话读完整：

- 它不是容器，也不是 microVM；同一个用户下的其他进程照样能碰到同一个工作目录；
- 它挡的是**这条进程树自己越界**——即 agent 自作主张动了工作目录之外的东西这类意外与误操作；
- 它挡不住一个铁了心要逃逸的对手。macOS 上的 `sandbox-exec` 已被 Apple 标注为 deprecated。

**宁可失败，不可静默降级**：开了沙箱却拿不到工具（`sandbox-exec` / `bwrap`）时，
daemon 会**明确报错**，而不是"那就直接跑吧"。静默降级会让你在**以为自己被保护着**的情况下裸奔——
那种失败比"功能没做"严重得多，因为它把安全感本身变成了假的。

更彻底的隔离请用**专用 Unix 用户 → 容器 → 独立 VM**。这三种都不在本项目范围内。

## 快速开始

需要 **Node ≥ 22**（推荐 24）。

```bash
pnpm install
pnpm run build:web      # ⚠️ 必做一次：界面是构建产物，不进版本库

# 1) 本机 daemon：托管界面与本地接口
pnpm run daemon
#    → http://127.0.0.1:4517

# 2) 远端服务（可选）：账号 / 设定 / 公共目录 / 第三方查询 / 记录统计
pnpm run remote
#    → http://127.0.0.1:4518

# 3) 对外 MCP server（可选，stdio）：让别的 agent 驱动本系统
pnpm run mcp

# 4) 命令行（可选）：人和脚本用。它是 daemon 的客户端，需要 daemon 在跑
pnpm run cli status
```

> ⚠️ 不要写成 `pnpm run daemon -- --port …`。pnpm 会把那个 `--` 一并传给程序，
> 而参数解析器见到 `--` 就会把**后面所有选项都当成位置参数**，于是选项全部失效。
> 所以 daemon 与 CLI 遇到 `--` 都会**直接报错**，而不是静默回落。

端口是**固定**的。端口被占用时 daemon **大声失败**，不会静默换端口——
随机端口意味着"重启后地址变了"，而地址会被写进书签与配置里，漂移比端口冲突更难排查。

数据目录默认 `~/.alpha-helper/data`（可用 `--data-dir` 覆盖）——那是**程序内部**状态：
SQLite、锁、blob 日志，所以它是隐藏的。

任务的工作目录默认在 **`~/alpha-helper-workspace/`**（可用 `--work-root` 覆盖）——
那是 **agent 真正的产出**，所以它**在家目录下、不隐藏**，方便你用 Finder 打开或
在终端里 `cd` 进去。刻意不放在数据目录里面：`~/.alpha-helper/data/work/…` 既点开头
又埋两层，"产出放在找不到的地方等于没有产出"。每个任务一个目录
（`<类型>-<id>`，同一个任务的重试会落回同一个目录），目录**根**一改会连带把旧目录搬过去。

### 常用命令

| 命令 | 说明 |
|---|---|
| `pnpm run daemon` | 起本机 daemon（界面 + 接口） |
| `pnpm run remote` | 起远端服务 |
| `pnpm run mcp` | 起 MCP server（stdio） |
| `pnpm run build:web` | **构建界面**（clone 之后必做一次；产物在 `apps/web/dist/`，已 gitignore） |
| `pnpm run cli <命令>` | 命令行（`status` / `issues` / `reports` / `costs` / `audits-export` …）。默认输出 JSON，退出码 0 成功 / 1 业务失败 / 2 用法错误 / 3 连不上 daemon |
| `node apps/daemon/src/cli.ts --verify-runtime all` | 查看 CLI 版本验证状态，不起服务 |

开发用的命令（`dev:web`、`check`、`test`、界面布局检查）在 [`docs/README.md`](./docs/README.md)。

## 界面怎么用

侧边栏四项：**新建任务 / 任务清单 / 智能体 / Skills**。

| 视图 | 做什么 |
|---|---|
| 新建任务 | 填标题（+ 可选说明）就行——建完立刻派给 agent，不必再点一次"跑" |
| 任务清单 | **列表**：一条一行，左边清单右边详情；**看板**：按"实际进行到哪一步"分三列（执行中 / 待审查 / 已审查）。阶段是从执行记录**推出来的**，不是一个人工维护的状态字段 |
| 智能体 | 每个 agent 配指令、技能、角色（执行 / 审核）与它用哪个 CLI。执行者的「由谁审它」决定产出会不会被自动审核 |
| Skills | 安装 / 查看 skill。每个 skill 携带三要素：**审核标准** + **判决结构引用** + **允许触发的动作子集** |

### 跑完之后看的是「最后结果」

执行**中**显示「实时输出」（原始流水）；跑完自动切成「**最后结果**」：

- **左边**：最后那段产出，按 Markdown 渲染（标题、表格、代码块、图片）——
  产出里引用的图片直接从工作目录显示出来；
- **右边**：工作目录里的文件，点一下就能打开；
- 「看完整日志」随时能翻回原始的每一条工具调用。

工作目录里的产出文件（`html` / `svg` 之类）打开时是**隔离**的：里面的脚本能跑（所以画布页
能真的画出来），但它**读不到**你的数据，也调不动本机接口。

### 不满意就接着说

任务详情页底部有「**继续沟通**」：执行跑完之后直接写下一步要它做什么，会**接着上一次的会话**
继续，而不是从头再来一遍。三点要知道的：

- 用的是**同一个工作目录**（按任务分配），所以 agent 上次留下的文件还在；
- 会话恢复是**尽力而为**——CLI 拒绝恢复时（换版本、会话过期）日志里会明说"本次没有上文"，
  不会假装接上了；
- 它是一条**新的 run**（不是给旧 run 追加消息）：一次 run 的产出是不可变快照，
  往里塞新输入会让"它当时收到了什么"不可回答，审计链也就断了。

## 装 skill

Skills 视图右上角有「安装 skill」，两个来源：

| 来源 | 说明 |
|---|---|
| **路径 / GitHub 链接** | 填本地目录的绝对路径（`/Users/me/dev/my-skill`）或 GitHub 链接（仓库根 / `…/tree/<ref>/<目录>` / `…/blob/<ref>/…/SKILL.md` / Raw 链接） |
| **远端目录** | 从远端服务的公共目录里挑，按版本比较决定装 / 更新 / 退回 |

**两条路都要过同一关：来源里必须有 `SKILL.md`（大写）。** 技能是靠"把目录摆对"被 CLI
发现的，没有它就永远不会生效——而你会以为自己装好了。所以缺了会**当场拒绝**，并把那个目录里
实际有什么列出来，方便改对。大小写不对（`skill.md`）也会单独提醒：macOS 上能碰巧读到，Linux 上不行。

同目录下的其它**文本**文件会作为**支持文件**一起装上（含子目录，如 `scripts/check.sh`）。
**二进制文件会被跳过并列出来**——装进来会写坏，所以宁可如实说"没装它"。

**同名不会直接拒绝，而是先比较版本**：

| 本地 | 目录 | 按钮 |
|---|---|---|
| 没有 | — | 安装 |
| 版本相同 | 同一版 | **已安装**（不可点） |
| 版本更低 | 新版本 | **更新到 x.y.z** |
| 版本更高 | 旧版本 | **退回 x.y.z**（会说清是往回退） |
| 没有版本信息 | — | 替换本地同名（本机自建/从路径装的，无法判断是不是同一份） |

规则是"同名不静默覆盖"：**更新与替换都必须显式确认**，界面上就是那个按钮。

**注入的技能跑完会收掉**——任务的工作目录只装 agent 的产出。收尾只删**这个平台自己放进去的**
东西，你自己放在同一个目录里的技能**一个都不会动**，同名时也会直接报错让你改名而不是覆盖。
"它当时是在什么标准下干活的"不会因此丢掉：每次运行的日志里都有注入记录，标准全文也一直
存在技能里（界面「看标准」随时能看）。

⚠️ 目前**没有卸载**：装了要删只有改库。这是已知缺口。

### 我们不会动你的 CLAUDE.md

任务交给 CLI 的方式是一段**组装好的"第一句话"**（身份、你给这个 agent 写的角色、
任务正文、技能清单、护栏；审核时还有待审材料、审核标准与判决格式要求）。
同一份文本另留一份**我们自己的**副本：`工作目录/.alpha-helper/context/<runId>.md`，
每次运行一份、互不覆盖——用途只是"回看它当时被交代了什么"和"让 agent 需要时可以重读"。

所以：

- **你的 `CLAUDE.md`（或你绑定仓库里的那个）我们一个字都不写、也不改**；
- 每次运行的工作目录里，除了 agent 的产出，只有那份 `.alpha-helper/` 副本。

## 你的数据去了哪里

远端同步**不经过 daemon**——daemon 不向任何远端发起请求。所以**页面**同时连着两边，
并负责三件事：

| 做什么 | 方向 |
|---|---|
| 定期问远端"有没有待处理项" → 取回后投给本机 daemon 走审核流程 | 远端 → 页面 → 本机 |
| 把**摘要**（用量、状态）上报到远端 | 本机 → 页面 → 远端 |
| 远端不可达时**本地暂存、恢复后补交** | — |

**上报什么**：只有摘要——执行的用量与状态、任务的状态变更。**不含** prompt 正文、
代码、报告原文；摘要只用于去重与统计。远端那份副本是**同步快照，不具证据效力**，
权威记录在本机 daemon 里。

可以在远端设定里用 `reportingEnabled: false` 关闭上报。关闭后本机功能**完整可用**；
远端整体不可达时同样如此。

**唯一一处 daemon 会主动出网**：从**本地路径 / GitHub 链接**安装 skill 时由 daemon 自己下载
（本地目录路径页面读不到，而"下载到本地"本来就发生在这台机器上）。这条路只允许 https、
只允许 GitHub 的几个主机、每一跳跳转都重新校验主机，并限大小 / 文件数 / 超时。
它**不涉及 alpha-helper 的远端服务**。

## 边界与信任模型

1. **浏览器是唯一的远端通道。** 页面由本机 daemon 托管，因此**同源**——跨源那一整套
   （Origin 白名单、一次性令牌、私有网络预检）都不需要，只剩"只绑回环 + 校验 `Host`"两条。
2. **daemon 不向 alpha-helper 的远端服务发起请求。** 它是本机服务，只接收浏览器的操作。
   远端只承担五件事：账号登录、用户设定、公共 SKILL/TOOL 目录、第三方查询转发、记录统计接收。
   （上面那处 GitHub 安装的例外是唯一的出网路径。）
3. **审核者 ≠ 执行者**，且**动作只能由判决触发**，链路有深度上限与环检测。
   这三条是硬不变量，在写库之前强制校验，不会被静默降级。

```
浏览器页面 ──同源──▶ daemon（界面 + 全部权威数据与本机执行）
     │
     └──跨源──▶ 远端服务（账号 / 设定 / 目录 / 第三方转发 / 统计）
                 ※ 页面直连；daemon 不参与这一跳
```

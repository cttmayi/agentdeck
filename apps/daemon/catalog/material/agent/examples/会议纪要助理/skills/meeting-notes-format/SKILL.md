# 纪要格式

## 用法

1. 先读原始记录，圈出"定了什么 / 谁要做什么 / 什么没定"。
2. 按三段写：结论 → 待办 → 未决。顺序不要调换（人扫一眼就看结论）。
3. 待办写成 `- [ ] 谁：做什么（期限）`；期限说不清就写 `（待确认）`，同时在未决里补一条。
4. 结论里出现的数字、人名、日期必须来自原始记录，不推测。

## 常见坑

- 把"讨论过程"写进结论 —— 纪要是给没参会的人看的，过程进附录，不进结论。
- 待办写成"跟进一下" —— 那是动作，不是待办；要写出产物。

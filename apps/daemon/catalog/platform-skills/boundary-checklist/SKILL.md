# 边界自检清单

给「智能体生成者」用：写完岗位卡的「边界（不能碰）」节之后，逐条过一遍这份清单。

## When to Use

起草 `agent-draft.md` 的边界节时；以及用户说"没有边界 / 你看着办"而你要给最小权限缺省段时。

## Procedure

边界节写完，逐条对照：

1. **不可逆操作**：删除、覆盖、改写他人文件、对外发送（发消息/发邮件/推送）——这类动作要么明令禁止，要么写明"必须先停下来问"。
2. **拿不准先停下**：缺关键信息时不猜、不编，先问——写成一条明确规则，不是靠"一般应该"。
3. **只在工作目录动手**：所有产出落进自己的工作目录；目录外的读写一律禁止。
4. **"没有"也要明说**：用户说没有边界时，写最小权限缺省段，并注明"这是缺省的最小权限"——不能把边界节留空。
5. **决定权归人**：替人做决定的事（判对错、定优先级、替人承诺）默认不碰；判据在审核者身上时，写明"只列不判"。

全部符合才算边界节合格；任何一条不适用就删掉那条，但**不得出现"边界节整个没有"**。

# 示例工具：模型调用（example-llm）

**远端目录里的范例包，专门用来测试动作参数**——特别是「模型」这一大类，以及**带数值边界**的整数参数。

## 它演示什么

`example-llm.call` 模拟一次模型调用，但**不真的调**：它把收到的**完整调用参数**追加写到
工作目录的 `llm-calls.jsonl`（一行一次调用），并逐项写出参数类型。装好之后建一条任务、
让审核者在判决里引用这个动作，然后打开工作目录里的 `llm-calls.jsonl`，就能看到
"这次判决让脚本用哪个模型、多大温度、多少个 token"。

## 参数一览

| 参数 | 类型 | 平台是否要求 | 怎么填 |
|---|---|---|---|
| `model` | **enum**（模型） | 必填 | `deepseek-v4` / `gpt-4o` / `claude-sonnet-4` / `qwen-max` / `llama-3.3` 五选一 |
| `prompt` | string（≤4000） | 必填 | 给模型的提示词 |
| `temperature` | integer（**0–100**） | 必填 | 采样温度 ×100（用整数避开小数校验的歧义） |
| `max-tokens` | integer（**100–100000**） | 必填 | 输出上限 |
| `stream` | boolean | 必填 | 是否流式 |
| `dir` | bound（`workdir`） | 平台注入 | 模型看不见、也填不了 |
| `run-id` | bound（来源 `subject.runId`） | 平台注入 | 触发这次动作的那条 run 的 id |

## 为什么这样设计

- **enum 演示"模型"这一类**：模型名是有穷枚举——`temperature` 填 `0.7` 会怎样？模型名
  填一个没接入的型号会怎样？都在判决校验时按这份清单挡住；脚本里再把**实际收到的类型**
  写进记录，校验没拦住的问题在这里一眼可见。
- **整数带边界**：`temperature`（0–100）与 `maxTokens`（100–100000）演示"数值参数有
  min/max"——平台在判决校验时就拒绝越界值，脚本永远拿不到 `temperature: 150` 这种输入。
- **长字符串上限**：`prompt` 限 4000 字，演示"开放字符串必须有界"（无界字符串等于让
  模型往你的系统里塞任意内容）。

## 怎么用（端到端测一遍）

1. 「工具」页 → 从**远端目录**安装 `example-llm`。
2. 挂到一个**执行者**身上（执行者的能力是工具，与动作权限无关）。
3. 在**审核者**的「行动权限」里允许 `example-llm.call`。
4. 新建任务跑一次；判决里 `action: { "type": "example-llm.call", "params": { "model": "…", "temperature": 30, "max-tokens": 4096, … } }`。
5. 判决通过后脚本执行；打开那条任务的工作目录，看 `llm-calls.jsonl`。

⚠️ 它刻意**只往工作目录写一个文件**：范例不该在你的机器上动别的东西。

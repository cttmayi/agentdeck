# 远端示例工具（hello-tool）

这是**远端目录**里的简单范例，用来演示「从远端目录安装」这条路。

```
hello-tool/
  tool.json            ← 机器读的清单（判据就是它的 schema）
  TOOL.md              ← 你正在读的这份说明
  scripts/say.mjs      ← 入口脚本
```

- 一个包 = 一个组；装一次，里面的动作一起进来。
- 它只声明了一个动作：`hello-tool.say`。
- 装进来之后，把它挂到一个**执行者**身上，审核者就可以在判决里引用
  `hello-tool.say`（审核标准里要先允许它）；判决通过时平台会执行这个脚本。
- `dir` 由平台绑定（那次执行的工作目录），`message` 由模型填。

⚠️ 它刻意**只往工作目录写一个文件**：范例不该在你的机器上动别的东西。

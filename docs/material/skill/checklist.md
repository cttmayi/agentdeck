# 入库前的体检（平台会逐条查）

这份清单与平台的机械体检**同一套判据**（`validateArtifactFiles`）。写完自查一遍，能省一次往返。

## 硬失败（任何一条都进不了库）

- [ ] **有 `SKILL.md`**（缺它就不是技能）。
- [ ] `SKILL.md` 第一行就是 `---`（frontmatter 必须在开头；前面多一行就认不出）。
- [ ] frontmatter 里有 `name`，且是 **kebab-case**（`^[a-z0-9][a-z0-9-]{0,62}$`）。
- [ ] frontmatter 里有 `description`，且非空（模型靠它决定何时加载）。
- [ ] 每个文件路径**安全**：不许 `..`、不许绝对路径、不许反斜杠。
- [ ] 单文件 ≤ **256 KB**；全部文件合计 ≤ **1 MB**；文件数 ≤ **64** 份（多了就合并同主题文件）。
- [ ] 每个文件都是 **UTF-8 文本**（二进制放不进来）。

## 建议（不拦，但会让人用起来费劲）

- [ ] 正文里有"常见坑"一节。
- [ ] 支持文件在正文里**被指路**（否则模型不知道它们存在）。
- [ ] `description` 写清"做什么 + 什么场景用"，不要只写一句口号。
- [ ] 没有把这次任务的细节写进去（那是任务笔记，不是技能）。
